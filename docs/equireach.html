Can this be used with real data?
          
Yes, but only locally or on infrastructure you control. This page prepares a valid payload.json from real child‑level data if you have lawful authority. The public demo server will not run real child data. A validated priority score is required; raw attributes plus an out‑of‑school label are not enough without first running the risk pipeline or an approved model. For restricted .sav microdata, use the local kit on an authorized machine, not this browser.

        

        
If you want a hosted web app for your organization
          
Deploy the same backend behind authentication on infrastructure you control, with consent capture, encrypted storage if data is retained, and a retention/deletion policy. Never use the free public endpoint for real child data. The front end can point to a private API base URL via an environment variable as a separate deployment.

        

      

    

  


  

    
About. This tool helps decide who receives support under a fixed budget. Deciding where to build centers is a separate question and is not part of this demo.

    
The real study. In the published study on real rural Chattogram data (Bangladesh MICS 2019; 4,861 children, support budget 730), reaching younger children proved expensive — the no‑floor plan selected only about 0.14% young children — while gender parity was comparatively cheap (no‑floor 29.04% girls), and the two coverage floors were subadditive in cost (interaction −5.740). This live demo uses fictional, deliberately balanced children, so its numbers differ from the real study (here the two floors come out additive).
